# Full Stack

Planning is the default. Read `flows/design.md` first for every request; it calls the other flows. Deployment, publication, tool installation, and delegation follow their own permissions, never build authorization alone.

References under `references/` are consulted only when a flow step names them.

| Read | When |
|---|---|
| `flows/design.md` | Always first: scope, design, registry, and the choice between design-only delivery and implementation |
| `flows/research.md` | Called by the design flow when uncertainty could change the design |
| `flows/implement.md` | Called by the design flow when the request asks to build or implement |
